# Pixelgrid 1.5.0: News variant implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the News portal starting point on the variant system, released as 1.5.0. It has its own palette, serif type, masthead, footer, front page, section fronts and article template, plus 15 articles.

**Architecture:** News is one more variant file (`inc/variants/news.php`) plus a style variation (`styles/news.json`), patterns (`patterns/news-*.php`) and images. The setup layer gets four general extensions that News needs first and Shop can reuse:
- posts in more than one category
- category links in the menu
- category IDs filled into query blocks at setup
- categories created before pages

The theme also gets two small front-end helpers, both presentation only:
- a "today's date" block binding for the masthead
- a "related posts" query filter for article pages

No fixed format from 1.3.0 changes.

**Tech Stack:** WordPress 7.1 block theme (theme.json v3), PHP 7.4+, the WP-CLI test harness in `tests/`, and phpcs (WPCS 3) installed outside the repo.

**Spec:** `docs/superpowers/specs/2026-11-18-variants-design.md`, sections 2, 5, 6.1 to 6.5, 6.7 and 10. Rulings and lessons from 1.4.0 are in `.superpowers/sdd/2026-11-19-variants-1.4.0/progress.md` in the 1.4.0 worktree.

## Global Constraints

- **Platform:** block theme, theme.json version 3, `Requires at least: 6.6`, `Tested up to: 7.1`, `Requires PHP: 7.4`.
- **Strings and prefixes:**
  - Text domain is `pixelgrid`.
  - Every user-facing string is translatable and lives in PHP patterns, not `.html` files.
  - Prefixes: `pixelgrid_` for functions and options, `pixelgrid/` for pattern slugs and binding sources, `pixelgrid-` for pattern categories, handles and marker classes.
- **Consent:** nothing is created or changed until the user ticks options and clicks a button on Appearance > Pixelgrid setup.
- **Self-contained:** no runtime external calls, no remote files, no bundled plugins.
- **Fixed formats from 1.3.0 do not change:**
  - the `pixelgrid_starter_*` options and the structure of `pixelgrid_starter_design`
  - the marker `_pixelgrid_starter` = `{variant}:{key}`
  - IT and Agency keys
- **Upgrades:** a 1.4.0 site with IT or Agency starter content, updated to 1.5.0, looks and behaves the same and removes cleanly.
- **Contrast:** in every tone of every variant, text on background is at least 4.5:1 and text on the hover colour is at least 4.5:1.
- **Identity:** News keeps the Pixelgrid identity: the 24-cell grid, mosaics, section tones, uppercase condensed labels and pixel-notch images.
- **Fonts and images:**
  - Bundled, GPL-compatible and credited in `readme.txt`.
  - Images are own work generated by `tools/make-plates.php`.
  - The News serif is Newsreader (SIL OFL 1.1, from Google Fonts). This is a one-time download that needs the owner's go-ahead.
- **No hardcoded IDs:** no post, term, menu or media IDs in theme files. Category IDs reach query blocks only at setup time, in the created pages.
- **phpcs:** the WordPress standard and PHPCompatibilityWP with testVersion 7.4- report 0 errors and 0 warnings on `functions.php`, `inc/` and `patterns/` before release.
- **Test-site lessons from 1.4.0:**
  - Tests and browser checks run setup as `--user=freshadmin`.
  - Pages are checked with plain permalinks: `?pagename=` and `?cat=` URLs.
  - Phone width is checked in a 390px iframe, because headless Chrome does not go below 500px.

### Task 1: Setup extensions for categories, and the two front-end helpers

**Files:**
- Modify: `inc/starter-content.php`, `functions.php`
- Create: `inc/front.php`, `tests/test-front.php`
- Test: `tests/test-starter.php` (add), `tests/test-front.php`. Use the fixture variant pattern from `tests/fixtures/` and register a test variant through the `pixelgrid_variants` filter.

**Interfaces:**
- Produces, used by Tasks 4 and 5:
  - **Post `category`** may be a string or an array of slugs. The first one is the primary category.
  - **Menu entries** may be `'cat:{slug}'`. That entry becomes a `core/navigation-link` with `"type":"category"`, `"kind":"taxonomy"`, `"id":{term_id}` and `"url":get_category_link()`. An entry is skipped if the category does not exist.
  - **`pixelgrid_starter_categories( array $def ): array`** returns slug → term_id. It creates missing categories, records new ones in `pixelgrid_starter_terms`, and runs when the Pages or Posts option is ticked, before pages are created.
  - **`pixelgrid_starter_fill_categories( string $content, array $cats ): string`** walks the block tree with `parse_blocks`. For every `core/query` block whose `className` contains `pixelgrid-cat-{slug}` with `{slug}` in `$cats`, it sets `attrs.query.taxQuery.category = array( $cats[ $slug ] )`. Content with no such block returns unchanged, byte for byte. Only changed content goes through `serialize_blocks`.
  - `pixelgrid_starter_create()` applies `pixelgrid_starter_fill_categories()` to every starter page it creates or finds, after categories exist.
  - **Binding source `pixelgrid/today`**, registered on `init` with `register_block_bindings_source()` and label "Today's date". It returns `wp_date( get_option( 'date_format' ) )`, escaped. It needs no post context.
  - **Related filter:** `pixelgrid_related_query_vars( array $query, WP_Block $block ): array` on `query_loop_block_query_vars`. It only acts when the parent query block's `className` contains `pixelgrid-related` and `is_singular( 'post' )` is true. It then sets `category__in` to the current post's category IDs, `post__not_in` to the current ID, and `ignore_sticky_posts` to true. With no categories it sets `post__in = array( 0 )`, so the row is empty.

### Task 4: News patterns

**Files:**
- Create `patterns/news-*.php`. Their category is `pixelgrid-news` ("Pixelgrid News") unless noted.
  - Parts:
    - `news-header.php` (Block Types `core/template-part/header`): the masthead. A date line paragraph bound to `pixelgrid/today` sits next to the condensed label "Edition".     - `news-footer.php` (Block Types `core/template-part/footer`): five category columns. Each heading links to `add_query_arg( 'category_name', '{slug}', home_url( '/' ) )`. They are followed by an About, Tips and Contact links row and the copyright.
  - Sections:
    - `news-lead.php`: the lead story. A query of 1 post with a large image, title, excerpt and byline.
    - `news-top-stories.php`: a 3-column grid query of posts 2–4, using `offset` 1.
    - `news-category-row.php`: a generic row of the 4 latest posts with no category filter, for the inserter.
    - `news-row-world.php`, `news-row-business.php`, `news-row-technology.php`, `news-row-culture.php` and `news-row-sport.php` (`Inserter: no`): the same row, labelled with the category name. The query has the marker class `pixelgrid-cat-{slug}` and the heading links to the category. These share their markup through one helper, `pixelgrid_news_row( string $slug, string $label ): void`, in `inc/news-row.php`.     - `news-opinion.php`: an opinion column with a pull quote and the 2 latest posts in a `pixelgrid-cat-opinion` query. Opinion is a category in Task 5.
    - `news-tips-cta.php`: the call to action linking `?pagename=tips`.

    - `news-template-single.php`: category label (post-terms), title, standfirst (`core/post-excerpt`), byline (author name + date), featured image, content, tags, then the related row. That row is a query with class `pixelgrid-related`, 3 posts, `inherit` false.

Use two inherited queries with offset, or one query with a first-item style. The implementer chooses; the editor must show no invalid blocks either way.
